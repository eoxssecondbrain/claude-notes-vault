User: . How to create a project in Claude.

Assistant: To create a project in Claude:

1. Go to claude.ai/projects, or click "Projects" in the left sidebar.
2. Click "+ New Project" in the upper right.
3. Give the project a name and description (Claude itself won't have access to these details, so they're just for your organization).
4. Upload relevant documents, text files, or code snippets — Claude will use these as context in all chats within the project.
5. Optionally, set project instructions — Claude will use these instructions for all the chats within the project.

Note: context is not shared across chats within a project unless the information is added to the project knowledge base. Projects are available on all plans, including free, though free users are capped at five projects.
