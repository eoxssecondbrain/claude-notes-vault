**User:** Can you provide me some details on how proposals are created ?

**Assistant:** Based on what's documented internally, EOXS doesn't have one fixed "proposal template" — it's a sales-led deck that gets rebuilt and customized per deal, but a recurring structure keeps showing up:

**The deck itself**
The earliest documented version is a "Client Proposal" PDF Remya Mohanan (GTM lead) sent for review in 2021, alongside a "Post Demo Sequencing + Content" sheet. It used a golf-swing metaphor (the "9 Hole Implementation Plan") to frame ERP adoption, with Cost-vs-Benefit and Data Security sections built out as the deal progressed. A more finished 14-page version ("Enterprise Resource Planning") was sent to the same prospect about ten weeks later — so drafts iterate before a "final" deck goes out.

**The pricing structure behind it**
Proposals are generally built around:
- An implementation build rate (e.g. $5,500/week, seen in the Bri‑Steel proposal)
- An onsite rate ($/hour for on-site work)
- A per-user monthly license fee
- A multi-year contract term with a capped annual price increase (≤4% shows up repeatedly)
- A defined "go-live" trigger (e.g. first PO generated in the system)

**But pricing varies a lot deal-to-deal** — implementation fees documented range from a $5,000 flat fee (RW Conklin) up to $273,000 over 35 weeks (Harbor Pipe, a much larger prospect), and one comparison flagged a ~20x gap between two proposals signed in the same quarter (Amix Group vs. Camden Yards Steel). So proposals aren't generated off a rate card — they're scoped per-client based on user count, modules, and negotiated discounts (sign-by-deadline discounts appear more than once).

Worth flagging: this is reconstructed from sales emails and internal analysis pages spanning 2021–2026, not a formal step-by-step SOP — no dedicated "how to build a proposal" document exists in the reference library, just the deals themselves.

Sources: EOXS Sales Collateral — Client Proposal Deck (2021), EOXS Full Implementation Proposal Pricing Model — both eoxs-db wiki, tier2_confidential.
